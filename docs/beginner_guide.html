カメラも人感センサーも置かずに、部屋を飛び交う Wi-Fi 電波のわずかな揺らぎだけを見て「人がいるか」「窓が開いているか」を AI に当てさせる自動実験装置です。

✅ ステップ 1：完了

電波録音機をつくる

ラズパイの Wi-Fi を改造（Nexmon）して、普通の PC では見えない「電波の細かい波（CSI）」を録音できるようにした。
✅ ステップ 2：稼働中！

24時間自動で貯める

ラズパイが 5 分ごとに電波を録音し、スマホで押した答え（在室/窓開閉）と一緒に Google Drive (5TB) へ日付別で自動保存中！（すでに 12.6GB 収集済み）

🍓 Raspberry Pi 4B（超精密な録音機）

役割：部屋の Wi-Fi 電波の揺らぎを 24時間休まず記録し、Google Drive へ運ぶ係

手のひらサイズの小型 Linux パソコンです。普通に使うと「電波が強いか弱いか（1個の数字）」しか見えませんが、Nexmon という改造ファームウェアを入れたことで、1秒に約90回・256本の周波数ごとの波（CSI）を記録できるようになりました。また、スマホから開ける小さな Web サイト（ポート8080）も裏で動かしています。
